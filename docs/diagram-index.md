# ScamTrace Engine Diagram Index

This folder contains the main technical diagrams for the ScamTrace Engine capstone project.

## Diagrams

1. Architecture Diagram  
   File: `architecture.md`  
   Purpose: Shows the full system structure from public data sources to reporting outputs.

2. Entity Relationship Diagram  
   File: `erd.md`  
   Purpose: Shows the planned database tables and relationships.

3. Data Flow Diagram  
   File: `data-flow.md`  
   Purpose: Shows how scam data moves through collection, processing, classification, and output.

4. Processing Pipeline Diagram  
   File: `pipeline.md`  
   Purpose: Shows validation, filtering, normalization, keyword extraction, and classification logic.

5. Dashboard and Reporting Output Diagram  
   File: `dashboard-output.md`  
   Purpose: Shows the final reports, dashboard cards, and stakeholder outputs.
